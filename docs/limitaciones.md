# Limitaciones conocidas

**Estado:** Borrador inicial; ampliar durante el desarrollo  
**Responsable:** TODO: nombre

- **Cobertura incompleta:** las plataformas pueden limitar resultados por consulta y no necesariamente devuelven todos los negocios de una ciudad.
- **Cambios de fuente:** los esquemas, límites y disponibilidad de datos pueden cambiar.
- **Restricciones de acceso:** se deben revisar los términos de servicio y métodos permitidos de cada fuente. No se debe asumir que una técnica de extracción es válida para todas las plataformas.
- **Contactos incompletos:** puede que solo exista un teléfono general, sitio web o ningún dato de contacto verificable.
- **Datos desactualizados:** calificaciones, reseñas y contactos pueden cambiar; la frecuencia de actualización aún debe confirmarse.
- **Duplicados:** negocios con nombres similares o sucursales pueden confundirse si no se define una clave estable.
- **Ambigüedad de reseñas:** una reseña negativa no demuestra por sí sola un problema sistemático o una crisis reputacional.
- **Errores de IA:** etiquetas, resúmenes y borradores pueden ser incorrectos; requieren revisión humana.
- **Privacidad y uso de datos:** el equipo debe documentar qué datos guarda, durante cuánto tiempo y con qué propósito.
- **Escalabilidad:** la meta de 200 leads corresponde a la demostración; no demuestra por sí sola capacidad de producción a gran escala.
