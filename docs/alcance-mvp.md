# Alcance del MVP

**Estado:** Pendiente de validación con el equipo  
**Responsable:** A Definir

## Objetivo
Demostrar que RepuSense puede encontrar y organizar prospectos con señales de problemas reputacionales y ayudar al equipo comercial a priorizarlos.

## Funcionalidades propuestas
- [ ] Búsqueda por ubicación y rubro.
- [ ] Filtros por calificación y cantidad de reseñas.
- [ ] Extracción y persistencia de negocios desde una fuente acordada.
- [ ] Detección o resumen del problema principal a partir de reseñas disponibles.
- [ ] Dashboard de resultados.
- [ ] Datos de contacto disponibles.
- [ ] Estado de seguimiento comercial.
- [ ] Exportación CSV.
- [ ] Borrador de correo personalizado con IA.

## Fuera de alcance / por confirmar
- Envío automático de emails.
- Garantía de cobertura exhaustiva de todas las ciudades, países o plataformas.
- Operación productiva a gran escala.
- Enriquecimiento de contactos con datos no públicos.

## Criterios de demo
- [ ] Ejecutar una búsqueda de punta a punta.
- [ ] Mostrar filtros y resultados guardados.
- [ ] Demostrar manejo de duplicados o actualización de registros.
- [ ] Exportar resultados a CSV.
- [ ] Mostrar un borrador de correo asistido por IA.
- [ ] Alcanzar la meta de 200 leads reales durante las pruebas, según las condiciones acordadas.
